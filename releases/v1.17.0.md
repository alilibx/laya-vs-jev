date: 2026-11-11

The site now looks like a code editor, and every model shows its maker's logo. No score changes.

## The main page
- A title bar with search in the middle, and GitHub and theme buttons.
- An Explorer sidebar lists the page's sections as files (`leaderboard.tsv`, `index.chart`, `vision/`, `ROADMAP.md`, `results.json` and others) and highlights the one you're reading. Below it, a Makers list shows each maker's logo and model count; click one to filter every chart and table.
- A status bar shows the number of runs, the datasets, the data lock and the last update.
- Headings, numbers and labels are set in JetBrains Mono, longer text in IBM Plex Sans. The leaderboard sits in an editor tab.
- On a phone, the sidebar becomes a row of tabs that scrolls sideways.

## Maker logos
18 makers have a logo, taken from the open [LobeHub icons](https://github.com/lobehub/lobe-icons) (MIT) or the maker's own site icon. Individual developers and makers without a clear logo get their initials. Logos replace the colour swatches in the filter chips, tables and leaderboard. Each sits on a white tile so it stays visible in dark mode, with a small dot in the model's chart colour.

## The other pages
Model, comparison and benchmark pages use the same title bar, fonts and colours, and show logos in their headings and tables.
