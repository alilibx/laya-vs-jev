Round 11 runs Celeris-1 Decision and meraGPT's Decider 1 on their vendors' own APIs, with the same request bodies as every other model, on all 3,250 text cases. Celeris-1 goes straight to 4th on the System One Index. Decider V1.2 still leads.

## New on the board
| Model | Maker | System One Index | Rank | Calibration error | Cost per 1,000 calls |
|---|---|---|---|---|---|
| Celeris-1 Decision | Celeris | **83.6** | 4th of 37 | 2.6% | $0.014 |
| Decider 1 | meraGPT | 61.9 | 33rd of 37 | 7.9% | $0.012 |

- **Celeris-1 is 4th**, 1.0 point behind Decider V1.2 and 0.5 behind GLiDE and Drex Max, and 2nd on the English index. It answered every case.
- **Decider 1 rejects questions with more than 10 options**, so Banking77 and Arabic MASSIVE scenario and intent (600 cases) count as wrong. On its other 13 datasets it averages 75.5.
- **Neither has a vision score.** Celeris-1 accepts images but reads them as base64 text and scores at chance (50.0% on SST-2 from an image, against 95.5% on the same reviews as text). Decider 1 rejects every image as over its 4,096-token cap.

## Latency
This round ran from a machine whose round trips don't compare with the cloud server behind the board's timings, so neither model has latency on the board.

## Fixes
- `run_decisions.py` reads a cost reported as a string, as meraGPT's API does (`"$0.000007"`), so `score.py` can sum it.
