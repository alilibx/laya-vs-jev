Round 10 runs Fastino GLiDE on its own API, with the same request bodies as every other model, on all 3,250 text cases and the 5 Vision Index datasets. It goes straight to 2nd on the System One Index. Decider V1.2 still leads.

## New on the board
| Model | Maker | System One Index | Rank | Vision Index | Rank |
|---|---|---|---|---|---|
| GLiDE | Fastino | **84.1** | 2nd of 35 | 82.5 | 7th of 13 |

- **GLiDE is 2nd**, 0.5 points behind Decider V1.2 and 0.04 ahead of Drex Max. It's also 2nd on the English and Arabic indexes.
- **The score held up.** A second full run, not published, scored the same index (84.13), with 7 answers changed out of 4,850.
- **It's 14th on calibration** (3.6%, against Decider V1.2's 0.7%), and costs $0.017 per 1,000 calls at the list price.
- **Arabic from a picture costs it 22.0 points** (51.5% on the images against 73.5% on the same tweets as text).
- GLiDE doesn't answer Box questions. The API reports the model as `glide_v2`, while the open weights are V1.2, so the board calls it GLiDE.

## Latency
This round ran from a machine whose round trips don't compare with the cloud server behind the board's timings: a control run of Jev 1.14 took 521 ms median there against 136 ms on the board. So GLiDE has no latency on the board.

## Roadmap
Removed: Fastino GLiDE, now on the board. Celeris-1 Decision, Hanzo Kai 1 and meraGPT Decider 1 stay on the list until their API keys are in place.
